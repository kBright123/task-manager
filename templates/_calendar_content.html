如何添加到手机日历？订阅失败怎么办？
· iPhone：日历 App → 底部「日历」→ 添加日历 → 添加订阅日历（iOS 26+ 可选 iCloud 账户），粘贴链接；添加后务必打开该订阅的「事件提醒」。
· 小米/红米：日历 App → 设置 → 日历账号管理（或右上角菜单）→ 从 URL 导入 / 订阅日历，粘贴链接。
· 华为鸿蒙 4.x / EMUI：日历 App → 设置（或「更多日历」）→ 添加订阅日历 / URL 订阅，粘贴链接。
· HarmonyOS NEXT（鸿蒙 5+）：自带日历暂不支持自定义 URL 订阅，请点上方「下载 .ics」后用日历/文件导入（一次性，不会自动更新），或使用支持 ICS 订阅的第三方日历。
· 订阅默认约每 1 小时自动刷新（iPhone 可在订阅日历详情或「设置 → 日历 → 账户 → 获取新数据」调整，也可在日历列表下拉手动刷新）；发布端的 REFRESH-INTERVAL 只是建议值，Apple 可能忽略。链接含个人令牌请勿外传，「重新生成」后旧链接立即失效。
订阅失败排查：
① 先用手机浏览器直接打开这个链接——能看到一堆 BEGIN:VCALENDAR 文本说明网络通，再去日历里订阅；打不开就是地址/网络问题（换局域网 IP、确认同一 Wi-Fi）。
② 复制的地址若是 localhost 或 127.0.0.1，手机上必然失败，必须改成服务器实际 IP。
③ 小米日历对格式严格且失败时不报原因：更新系统后重试；仍不行可用开源 App DAVx⁵（添加「Webcal 订阅」）中转。
④ 部分机型仅支持 https 订阅，内网 http 部署时建议用上面的一键添加或 DAVx⁵ 方案。
⑤ iPhone 点「手机一键添加」没反应：多半是从主屏幕图标(App)里打开的——App 内会拦截 webcal 协议，此时链接已自动复制，去 Safari 粘贴打开即可弹出订阅确认。
⑥ 同一条待办当天反复提醒：多为旧版订阅里的过期闹钟残留。在本站完成或删除该待办，同步一次即会撤销；若仍反复弹出，删除手机上的订阅日历后重新添加一次链接。
