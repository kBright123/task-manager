# 知行合一 · 任务与知识管理系统

一个集 **任务协作、知识管理、随手记、数字分身问答** 于一体的团队内网系统，基于 Flask 构建，针对低资源服务器（1核 / 512MB~2GB 内存）做了深度优化，全程开箱即用、无外部云服务依赖。

> 当前版本: `v0.7.0`

---

## 功能总览

| 模块 | 说明 |
| :-- | :-- |
| **任务协作** | 管理员发布任务、指派成员，成员领取后填写进度、上传交付物，主管审批/驳回，全流程留痕 |
| **随手记 (Notes)** | 个人 Markdown 笔记，按「对话线程/项目」组织，写笔记自动继承上下文，SIMHash 相似笔记提醒 |
| **知识库 (KB)** | 文档上传 → OCR / PDF 解析 → 知识点自动拆解 → 向量检索 → 数字分身问答 → 知识图谱 |
| **数字分身** | 基于已识别文档 + 大模型的 RAG 问答（默认关闭大模型时降级为关键词检索 + FAQ 摘要） |
| **自动分类归档** | fastText 对已识别文档自动归类并归档到对应合集（无模型时自动降级为关键词规则） |
| **统一检索** | 一个入口同时检索任务、笔记、知识库文档、知识点，并记录检索历史 |
| **邮件提醒** | 会议/培训/考试待办截止前 1 小时提醒负责人，工作日 9:00 发送待办日报 |
| **通知中心** | 站内实时通知，单条已读 / 全部已读 |
| **管理后台** | 用户与分组管理、邮箱验证、发送日志、系统日志、后台任务队列与定时任务 |
| **低资源模式** | 一键关闭 LLM / fastText / 向量检索，后台 worker 按需启停，内存占用降到最低 |

## 核心特性详解

### 1. 任务协作与审批流
- 管理员在后台创建任务并指派到用户/分组，可设置截止时间与类别（会议/培训/考试…）。
- 成员在「我的任务」中领取任务、更新进度、上传交付文件。
- 提交后由管理员审批，支持 **驳回** 与 **批准**，超时未处理自动提醒。

### 2. 知识库：从文档到知识
```
上传文档 → OCR/PDF 解析 → 自动分类归档 → 知识点自动拆解 → 相似关联 → 向量检索 → 问答/图谱
```
- **解析**：`pypdfium2` 解析 PDF（含文本层优先，可跳过 OCR），`RapidOCR` + `onnxruntime` 本地 OCR（支持 150+ 语言，中文效果好），`.txt/.md/.html` 直接读文本。
- **知识点拆解**：文档识别完成后自动拆分为若干「知识点」（优先按标题结构，无标题时用 TextTiling 语义切分），记录标题、页码、字数；支持对已识别文档免 OCR 一键「重新拆解」。
- **相似关联**：基于字符 bigram TF-IDF 余弦相似度，自动建立知识点间的相似关系，构成知识网络。
- **知识图谱**：ECharts 力导向图可视化知识点网络，按合集着色，点击节点直达知识点详情。
- **检索**：默认 SQLite 关键词匹配；开启向量检索后使用 `BAAI/bge-small-zh-v1.5` 嵌入 + SochDB 向量库。
- **问答**：检索 top-k 相关段落注入大模型生成带页码引用的答案（可选用本地 opencode 网关）。
- **安全上传**：文件头魔数校验，拦截「伪装成图片/文档的可执行文件」。

### 3. 自动分类（fastText）
- 以已有合集名作为类别标签，有监督训练 fastText 分类器，识别完成后自动归档。
- 冷启动零样本：无模型时用内置类别种子关键词打分兜底；自动创建合集并着色。

### 4. 随手记
- Markdown 按「年/月/日」分片落盘，结构化元数据存 SQLite，写入即用无需建索引。
- 上下文继承：笔记自动继承所在线程的项目/标签；SIMHash 近似度检测，提醒你「可能写过类似内容」。

### 5. 定时任务与黑名单清理（后台任务队列）
- **入队/消费模型**：`job_worker.py` 单实例轮询 `note_job` 队列（`JOB_INTERVAL` 秒一次），手动「立即执行」与自动定时均入队执行，执行全程记录阶段与结果。
- **自动整理**：默认每周六 22:00 对近 7 天有新增的笔记/知识库执行标签匹配、标题提炼、知识点合并/提炼、文档标题提炼；无新增则自动跳过。
- **自动清理黑名单字样**：默认每周日 03:00 扫描笔记、知识库主库与缓存，删除黑名单机构字样（默认 `邮储银行,邮储,邮政`，可用 `KB_TAG_BLACKLIST` 环境变量覆盖）。
- **自定义黑名单**：管理后台「定时任务」面板可配置自定义黑名单（逗号分隔），**定时与手动执行均生效**；留空则回退到系统默认。
- **任务管理**：`/admin/jobs` 支持一键「立即执行」入队、查看执行记录与分步结果、失败重试、停止排队/进行中任务。

### 6. 低资源模式（默认开启部分降级）
| 环境变量 | 默认 | 说明 |
| :-- | :-- | :-- |
| `KB_LLM_DISABLED` | `1` | 关闭大模型问答，检索降级为关键词 + FAQ |
| `KB_VECTOR_DISABLED` | `1` | 关闭 fastembed + SochDB 向量检索 |
| `KB_CLASSIFIER_ENABLED` | `1` | fastText 分类，无模型时自动降级关键词规则 |
| `KB_WORKER_ENABLED` | `1` | 后台识别 worker 按需启停 |
| `REMINDER_INTERVAL` | `300` | 邮件提醒扫描间隔（秒） |

## 技术栈

- **后端**: Python 3.11 · Flask 3 · Flask-SQLAlchemy · Flask-Login · Gunicorn
- **数据库**: SQLite（WAL 模式，单文件零运维）
- **OCR**: RapidOCR · onnxruntime · OpenCV
- **PDF**: pypdfium2
- **向量**: fastembed（BAAI/bge-small-zh-v1.5）· SochDB
- **分类**: fasttext（社区预编译 wheel）
- **前端**: 原生 HTML/CSS/JS · Bootstrap Icons · ECharts（知识图谱）
- **部署**: Docker · docker-compose

## 快速开始

### Docker 部署

```bash
git clone <your-repo-url>
cd task-manager

# 按需编辑 docker-compose.yaml 中的环境变量
# （默认已开启低资源模式，1核/512MB 即可运行）

docker compose up -d --build
```

访问 `http://<server>:5000`。首次启动会自动初始化一个管理员账号 `bright`（登录后请立即在个人中心修改密码），其余成员可自行注册。

### 本地开发

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 启动 Web 服务（可选 --debug）
gunicorn --bind 0.0.0.0:5000 --workers 2 app:app
```

> 知识库的文档识别在独立后台 worker 中执行，低资源模式下由 `entrypoint.sh` 自动按需拉起。

## 项目结构

```
├── app.py              # Flask 主应用：认证/任务/管理后台/统一检索/通知
├── knowledge.py        # 知识库：OCR/解析/知识点/相似关联/检索/问答/图谱
├── classifier.py       # fastText 文档自动分类与归档
├── notes.py            # 随手记模块（Markdown 落盘 + 上下文 + 相似提醒）
├── reminder_worker.py  # 邮件提醒后台进程
├── job_worker.py       # 后台任务队列消费（自动整理 / 黑名单字清理，单实例轮询）
├── entrypoint.sh       # 容器入口：起服务 + 按需拉 worker
├── scripts/            # 运维辅助脚本（如 clean_keywords.py 离线清理黑名单）
├── redeploy.sh         # 代码/模板改动后快速重启容器
├── templates/          # Jinja2 模板（base + 各模块页面）
├── static/             # JS/CSS/上传文件
└── instance/           # 运行时数据：tasks.db / 笔记 / 知识库数据 / 上传
```

## 环境变量速查

| 变量 | 默认 | 说明 |
| :-- | :-- | :-- |
| `KB_OPENCODE_BASE_URL` | `http://127.0.0.1:4096` | 大模型网关地址（数字分身问答） |
| `KB_OPENCODE_MODEL` | `deepseek-v4-flash-free` | 问答模型名 |
| `KB_EMBED_MODEL` | `BAAI/bge-small-zh-v1.5` | 向量嵌入模型 |
| `KB_SOCHDB_PATH` | `instance/kb_data/kb.soch` | 向量库路径 |
| `MAIL_SERVER` / `MAIL_USERNAME` / `MAIL_PASSWORD` | 空 | 邮件提醒 SMTP（未配置时校验码写入日志） |
| `KB_TAG_BLACKLIST` | `邮储银行,邮储,邮政` | 黑名单字样（逗号分隔，清理/标签兜底共用） |
| `JOB_INTERVAL` | `60` | 后台任务队列轮询间隔（秒） |
| `JOB_MAX_NOTES` / `JOB_MAX_KBS` | `80` / `40` | 每次自动整理处理的笔记 / 知识库上限 |
| `TZ` | `Asia/Shanghai` | 时区 |

## 安全与合规

- 文件上传做 **魔数校验**，防止伪装可执行文件入库。
- 密码使用 Werkzeug 哈希存储；支持邮箱绑定与验证。
- 知识库文档、合集支持公开 / 私有可见性控制，按上传者与管理员权限隔离。
- 密钥与 `.env` 不进入版本库。
