# 知行合一 · 任务与知识管理系统

一个集 **任务协作、知识管理、随手记、数字分身问答** 于一体的团队内网系统，基于 Flask 构建，针对低资源服务器（1核 / 512MB~2GB 内存）做了深度优化，全程开箱即用、无外部云服务依赖。

> 当前版本: `v1.1.0` · [更新日志](CHANGELOG.md)

---

## 功能总览

| 模块 | 说明 |
| :-- | :-- |
| **任务协作** | 管理员发布任务、指派成员，成员领取后填写进度、上传交付物，主管审批/驳回，全流程留痕 |
| **首页工作台** | 时间轴 + 日历双卡片一屏布局：8 个时间点折叠导航、节假日/班休角标、任务密度圆点、点日期筛选时间轴 |
| **随手记 (Notes)** | 个人 Markdown 笔记，按「对话线程/项目」组织，写笔记自动继承上下文，SIMHash 相似笔记提醒；支持图片粘贴/拖拽上传与附件 |
| **知识库 (KB)** | 文档上传 → OCR / PDF 解析 → 知识点自动拆解 → 向量检索 → 数字分身问答 → 知识图谱 |
| **数字分身** | 基于已识别文档 + 大模型的 RAG 问答（默认关闭大模型时降级为关键词检索 + FAQ 摘要） |
| **自动分类归档** | fastText 对已识别文档自动归类并归档到对应合集（无模型时自动降级为关键词规则） |
| **智能待办创建** | 一句话创建：「明天9点到下周五18点 @张三」自动解析标题/起止时间/负责人/分类，支持每天·每周X等重复周期 |
| **日历订阅** | 个人中心生成订阅链接，手机自带日历（iPhone/华为/小米等）添加一次即自动同步待办 |
| **待办回收站** | 待办删除进回收站，可恢复或彻底删除，防误删 |
| **暗黑模式** | 手动切换 + 记忆选择 + 默认跟随系统，全界面深浅色覆盖 |
| **快捷键 / PWA** | n 新建 · j/k 切换 · t 回今天；静态资源离线缓存二次打开更快 |
| **统一检索** | 一个入口同时检索任务、笔记、知识库文档、知识点，记录检索历史，点结果同页定位 |
| **快捷悬浮球 (FAB)** | 全站可用快捷入口：快速新建任务 / 随手记，有弹窗则内联打开，否则跳转对应页面 |
| **邮件提醒** | 会议/培训/考试待办截止前 1 小时提醒负责人，工作日 9:00 发送待办日报 |
| **通知中心** | 站内实时通知，单条已读 / 全部已读 |
| **管理后台** | 用户与分组管理、邮箱验证、发送日志、系统日志、后台任务队列与定时任务 |
| **体验登录** | 一键「体验登录」进入只读体验账号，可查看全部界面但禁止任何修改/添加 |
| **授权控制** | `born` 环境变量授权校验：未授权时拦截业务写入并提示「演示版本」，避免数据被改动 |
| **低资源模式** | 一键关闭 LLM / fastText / 向量检索，后台 worker 按需启停，内存占用降到最低 |

## 核心特性详解

### 1. 任务协作与审批流
- 管理员在后台创建任务并指派到用户/分组，可设置截止时间与类别（会议/培训/考试…）。
- 成员在「我的任务」中领取任务、更新进度、上传交付文件。
- 提交后由管理员审批，支持 **驳回** 与 **批准**，超时未处理自动提醒。

### 2. 首页工作台：时间轴 + 日历
- 双卡片一屏布局（PC 日历居左、时间轴居右），信息密度与操作效率兼顾。
- **时间轴**：8 个对称时间点折叠导航（更早→更远），滚动到位自动展开；卡片仅保留时间/标题/分类徽章；勾选完成即时生效；自动锚定今天并级联展开未来待办。
- **日历**：节假日名称与「休」/「班」角标直显、任务密度圆点、点日期筛选时间轴、Pad/手机滑动切月。

### 3. 智能待办创建（自然语言解析）
- 输入一句话即可成单：「开发登录功能 明天9点到下周五18点 @张三」——标题、起止时间、负责人、分类全自动解析。
- 支持「每天」「每周X」「每 N 周/月/年」重复周期；`KB_TIME_PARSER=jionlp` 可回退旧规则。
- 语言包未就绪时提示等待并暂停提交，杜绝静默解析错误。

### 4. 知识库：从文档到知识
```
上传文档 → OCR/PDF 解析 → 自动分类归档 → 知识点自动拆解 → 相似关联 → 向量检索 → 问答/图谱
```
- **解析**：`pypdfium2` 解析 PDF（含文本层优先，可跳过 OCR），`RapidOCR` + `onnxruntime` 本地 OCR（支持 150+ 语言，中文效果好），`.txt/.md/.html` 直接读文本。
- **知识点拆解**：文档识别完成后自动拆分为若干「知识点」（优先按标题结构，无标题时用 TextTiling 语义切分），记录标题、页码、字数；支持对已识别文档免 OCR 一键「重新拆解」。
- **相似关联**：基于字符 bigram TF-IDF 余弦相似度，自动建立知识点间的相似关系，构成知识网络。
- **知识图谱**：ECharts 力导向图可视化知识点网络，按合集着色，点击节点直达知识点详情。
- **检索**：默认 SQLite 关键词匹配；开启向量检索后使用 `BAAI/bge-small-zh-v1.5` 嵌入 + SochDB 向量库。
- **问答**：检索 top-k 相关段落注入大模型生成带页码引用的答案（可选用本地 opencode 网关）。
- **可见性**：文档/合集支持 公开 / 私有 可见性控制（支持文档级细粒度），按上传者与管理员权限隔离，并提供 API 令牌供外部集成。
- **安全上传**：文件头魔数校验，拦截「伪装成图片/文档的可执行文件」。

### 5. 自动分类（fastText）
- 以已有合集名作为类别标签，有监督训练 fastText 分类器，识别完成后自动归档。
- 冷启动零样本：无模型时用内置类别种子关键词打分兜底；自动创建合集并着色。

### 6. 随手记
- Markdown 按「年/月/日」分片落盘，结构化元数据存 SQLite，写入即用无需建索引。
- 上下文继承：笔记自动继承所在线程的项目/标签；SIMHash 近似度检测，提醒你「可能写过类似内容」。
- 富编辑：新建与编辑均支持 **图片粘贴/拖拽直接上传** 与 **附件上传**，图片/附件仅作为笔记内容保存，不入知识库。
- **标签**：随手记保存时可打标签（逗号分隔），成功后轻提示反馈。

### 7. 定时任务与自动整理（后台任务队列）
- **入队/消费模型**：`job_worker.py` 单实例轮询 `note_job` 队列（`JOB_INTERVAL` 秒一次），手动「立即执行」与自动定时均入队执行，执行全程记录阶段与结果。
- **自动整理**：默认每周六 22:00 对近 `job_cleanup_keep_days`(默认 7) 天有新增的笔记/知识库执行标签匹配、标题提炼、知识点合并/提炼、文档标题提炼；无新增则自动跳过。
- **自动清理黑名单字样**：默认每周日 03:00 扫描笔记、知识库主库与缓存，删除黑名单机构字样（默认 `邮储银行,邮储,邮政`，可用 `KB_TAG_BLACKLIST` 环境变量覆盖）。
- **每周数据备份**：默认每周一自动执行 SQLite 备份到 `backups/`，保留最近若干份，防止数据丢失。
- **自定义黑名单**：管理后台「定时任务」面板可配置自定义黑名单（逗号分隔），**定时与手动执行均生效**；留空则回退到系统默认。
- **任务管理**：`/admin/jobs` 支持一键「立即执行」入队、查看执行记录与分步结果、失败重试、停止排队/进行中任务。

### 8. 体验登录与授权控制
- **体验登录**：登录页提供「体验登录」按钮，一键以只读的 `guest` 体验账号登录，可完整浏览系统全部界面，但后端强制禁止所有 POST/PUT/PATCH/DELETE 业务写入（仅放行登录/退出），避免体验者误改数据。
- **授权校验**：正式版需配置环境变量 `born`，其值必须等于 `base64("MAIL_PASSWORD="+MAIL_USERNAME)`。未配置时系统进入「演示版本」模式，同样拦截业务写入并提示授权升级，保证数据安全。
- 两种只读限制均支持在管理后台创建正式用户后解除（授权后全量读写）。

### 9. 低资源模式（默认开启部分降级）
| 环境变量 | 默认 | 说明 |
| :-- | :-- | :-- |
| `KB_LLM_DISABLED` | `1` | 关闭大模型问答，检索降级为关键词 + FAQ |
| `KB_VECTOR_DISABLED` | `1` | 关闭 fastembed + SochDB 向量检索 |
| `KB_CLASSIFIER_ENABLED` | `1` | fastText 分类，无模型时自动降级关键词规则 |
| `KB_WORKER_ENABLED` | `1` | 后台识别 worker 按需启停 |
| `REMINDER_INTERVAL` | `300` | 邮件提醒扫描间隔（秒） |

## 技术栈

- **后端**: Python 3.11 · Flask 3 · Flask-SQLAlchemy · Flask-Login · Gunicorn
- **数据库**: SQLite（WAL 模式，单文件零运维）
- **OCR**: RapidOCR · onnxruntime · OpenCV
- **PDF**: pypdfium2
- **向量**: fastembed（BAAI/bge-small-zh-v1.5）· SochDB
- **分类**: fasttext（社区预编译 wheel）
- **时间解析**: jionlp（自然语言时间语义）· chinese-calendar（法定节假日/调休）
- **前端**: 原生 HTML/CSS/JS · Bootstrap Icons · ECharts（知识图谱）
- **部署**: Docker · docker-compose

## 快速开始

### Docker 部署

```bash
git clone <your-repo-url>
cd task-manager

# 按需编辑 docker-compose.yaml 中的环境变量
# （默认已开启低资源模式，1核/512MB 即可运行）

docker compose up -d --build
```

访问 `http://<server>:5000`。首次启动会自动初始化一个管理员账号 `bright`（登录后请立即在个人中心修改密码），其余成员可自行注册；登录页还提供「体验登录」按钮可直接以只读账号体验。

> 正式使用时，在 `.env` 中配置 `MAIL_USERNAME` / `MAIL_PASSWORD`，并设置 `born` 为 `base64("MAIL_PASSWORD="+MAIL_USERNAME)` 以通过授权校验（详见「授权控制」）。修改代码后 `docker compose up -d` 即可热加载（代码以卷挂载方式同步）。

### 本地开发

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 启动 Web 服务（可选 --debug）
gunicorn --bind 0.0.0.0:5000 --workers 2 app:app

# 回归测试（pytest 可选，零依赖也可跑）
pip install -r requirements-dev.txt
python tests/run_tests.py
```

> 知识库的文档识别在独立后台 worker 中执行，低资源模式下由 `entrypoint.sh` 自动按需拉起。

## 项目结构

```
├── app.py                # Flask 主应用入口（蓝图注册 / 授权控制 / 模板全局）
├── core/                 # 基础层：extensions(Flask扩展) · models · timeutil · app_services
├── kb/                   # 知识库域：knowledge(OCR/解析/检索) · classifier(fastText分类) · nlp_parser(时间解析)
├── routes/               # 路由域：auth · admin · tasks_pages/tasks_api/tasks_common · notes · search · notify
├── services/             # 业务服务：task_service(软删/恢复/彻底删除)
├── job_worker.py         # 后台任务队列消费（自动整理 / 黑名单字清理 / 周备份，单实例轮询）
├── reminder_worker.py    # 邮件提醒后台进程
├── backup.py             # SQLite 数据备份
├── entrypoint.sh         # 容器入口：起服务 + 按需拉 worker + jionlp 预装
├── templates/            # Jinja2 模板（base + 各模块页面）
├── static/               # JS/CSS/图标（sw.js 离线缓存）
├── tests/                # 回归测试套件（run_tests.py 零依赖可跑）
├── scripts/              # 运维辅助脚本
└── instance/             # 运行时数据：tasks.db / 笔记 / 知识库数据 / 上传（不入库）
```

## 环境变量速查

| 变量 | 默认 | 说明 |
| :-- | :-- | :-- |
| `born` | 空 | 授权校验：需等于 `base64("MAIL_PASSWORD="+MAIL_USERNAME)`，否则演示版拦截业务写入 |
| `KB_OPENCODE_BASE_URL` | `http://127.0.0.1:4096` | 大模型网关地址（数字分身问答） |
| `KB_OPENCODE_MODEL` | `deepseek-v4-flash-free` | 问答模型名 |
| `KB_EMBED_MODEL` | `BAAI/bge-small-zh-v1.5` | 向量嵌入模型 |
| `KB_SOCHDB_PATH` | `instance/kb_data/kb.soch` | 向量库路径 |
| `MAIL_SERVER` / `MAIL_USERNAME` / `MAIL_PASSWORD` | 空 | 邮件提醒 SMTP（未配置时校验码写入日志） |
| `KB_TAG_BLACKLIST` | `邮储银行,邮储,邮政` | 黑名单字样（逗号分隔，清理/标签兜底共用） |
| `JOB_INTERVAL` | `60` | 后台任务队列轮询间隔（秒） |
| `JOB_MAX_NOTES` / `JOB_MAX_KBS` | `80` / `40` | 每次自动整理处理的笔记 / 知识库上限 |
| `KB_TIME_PARSER` | `jionlp` | 待办时间解析引擎（`legacy` 回退旧正则规则） |
| `KB_PREINSTALL` / `KB_AUTOPIP` | `1` / `1` | 启动阻塞预装 jionlp / 运行时缺失自愈安装 |
| `KB_AUTOPIP_TIMEOUT` / `KB_PIP_MIRROR` | `600` / 清华源 | 自愈安装超时秒数 / pip 镜像源 |
| `TZ` | `Asia/Shanghai` | 时区 |

管理后台「定时任务」面板可在线调整：自动整理触发时间、黑名单清理触发时间、每周备份触发时间、清理保留天数（默认 7）、自定义黑名单等。

## 安全与合规

- 文件上传做 **魔数校验**，防止伪装可执行文件入库。
- 密码使用 Werkzeug 哈希存储；支持邮箱绑定与验证；失败登录锁定 + 邮箱验证码解锁。
- 知识库文档、合集支持公开 / 私有可见性控制，按上传者与管理员权限隔离。
- 体验账号只读、演示版本拦截写入，双重机制防止未授权数据改动。
- 密钥与 `.env` 不进入版本库。
